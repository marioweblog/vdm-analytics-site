Privacy policy

VDM Analytics · last updated 17 October 2026

VDM Analytics is a private, internal reporting tool. This policy explains how it handles Google user data.

What data it accesses

Only AdSense performance reports of the AdSense account that its owner authorises: earnings, impressions, clicks, page views, viewability and related metrics, broken down by date, site, ad unit, country, platform, operating system, browser and ad type. Access is read-only (https://www.googleapis.com/auth/adsense.readonly). It does not access email, contacts, files or any other Google data.

How it is used

The reports are used only for the owner's own analysis of their websites and advertising campaigns.

Storage

Report data and the authorisation token are stored only on the owner's own computer. They are not sold, shared with third parties, or used for advertising.

Sharing

Google user data is not shared with anyone outside the owner's own team, and never with third parties.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the app's local data removes everything it stored.

Google API Services User Data Policy

VDM Analytics' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
